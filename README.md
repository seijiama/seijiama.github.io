# netvisuals_

Portfolio site for Seiji Ma (@netvisuals_), hosted with GitHub Pages.

- `index.html`, `style.css`, `app.js`: the page
- `data.js`: the four sections, their thumbnails and every graphic, in order
- `images/`: web-sized copies of the graphics (longest side 1600px)

To add a graphic, put it in `images/` and add a line to its section in `data.js`.
